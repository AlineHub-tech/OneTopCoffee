# OneTopCoffee

A responsive coffee shop storefront for OneTopCoffee in Kigali, Rwanda. Browse seven product categories, search and filter the menu, choose a size, add products or combos to your bag, and place a delivery or pickup order.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

## Demo behavior

The storefront saves the bag, product availability and prices, and demo orders in the current browser's local storage. The menu includes hot coffee, iced coffee, milkshakes and smoothies, juices, cookies and biscuits, cakes and pastries, and coffee combos. Checkout records an order locally and displays a confirmation; it does not connect to a payment provider or send orders to a server. The team dashboard is a local demo and is not an authenticated admin system.
